# Спарта Плюс — дизайн-концепт

Полировка интерфейса: сохранены крупные заголовки и фотографии, выровнены кнопки, подписи и стрелки. Галерея заполнена выбранными фотографиями из проекта и поддерживает крупный просмотр, миниатюры и листание клавишами. В форме записи сначала выбирается зал, затем тренировка в этом зале; почта и опыт скрыты в необязательном раскрывающемся блоке. Диалоги блокируют прокрутку фона, удерживают клавиатурный фокус, закрываются по Escape и возвращают фокус на кнопку открытия. На телефонах предусмотрена нижняя кнопка записи, меню переключается раньше, чтобы пункты не накладывались друг на друга.

Перед переработкой расписания, цен и блока о клубе сохранён полный снимок исходников и фотографий: `../backups/sparta-reference-before-redesign-20261116-020819.zip`. Зависимости `node_modules` и сборка `dist` в резервную копию не входят; после восстановления выполнить `npm install`.

Текущий вариант: расписание таблицей «дни × залы» с фильтрами, датами, отменами и записью из ячейки; на телефоне — список по дням. На странице цен показаны бесплатное пробное и месячный безлимит без предварительной публичной цены. На главной — краткое знакомство с клубом и три шага до первой тренировки.

Последующие уточнения: у Акима занятия только в понедельник, среду и пятницу, суббота удалена из шаблона. Однократное обновление `sparta-fix-akim-no-saturday` исправляет и сохранённый список тренировок в браузере, сохраняя остальные настройки. Для фотографий зала добавлен плавный переход с учётом настройки уменьшения движения. На карточках тренеров кнопка «Ознакомиться» открывает профиль и актуальное расписание. В `COACH_PROFILES` предусмотрены `rank` (дан/квалификация), `startedYear` (начало тренерской работы), `referee` (судейская категория); незаполненные сведения не выдаются за подтверждённые. По последнему пожеланию сохранён крупный масштаб заголовков, фотографий, карточек и отступов.

Основа — присланный проект «Сайт клуба „Спарта“». Сохранены его композиция, типографика, навигация, страницы залов, тренеров, направлений, тарифов и административная панель.

Добавлен недельный календарь с тремя тренерами и тремя залами по данным, которые передал клуб. Пятничные занятия Дмитрия Михайловича на Иркутском тракте и Акима Дмитриевича на Фрунзе внесены по последнему сообщению. Время этих занятий пока принято таким же, как в другие дни соответствующих групп. Расписание находится на отдельной странице; на страницах залов оно не дублируется. Ссылки на адреса открывают поиск в 2ГИС.

Запись открывается из конкретной тренировки. Форма занимает примерно половину экрана; в ней выбираются тип занятия и участник, вводятся имя и телефон. Почта и прежний опыт занятий необязательны. Для ребёнка вводятся имя и возраст, контакт родителя виден администратору. Кнопка «Новая запись» в панели открывает форму по центру.

В панели клуба можно редактировать регулярные тренировки: тренера, зал, направление, дни и время; включать и приостанавливать их; отменять отдельную дату. Есть поиск и фильтры записей, звонок по номеру, копирование текста подтверждения и отметка посещения. Абонемент учитывается по месяцам: участника можно добавить на месяц, отметить оплату и её дату либо отменить ошибочную отметку. Все суммы пока демонстрационные.

Это локальный прототип. Записи, демо-профили, изменения расписания и оплаты хранятся в localStorage браузера, сервер клуба их не получает. Онлайн-оплата в публичном сценарии не предлагается. Имена посетителей в админке и финансовые данные — демонстрационные. Пробное занятие показано бесплатным; окончательную стоимость месячного безлимита и направления каждого занятия ещё нужно уточнить. В демонстрационном учёте администратора пока используется сумма 5 000 ₽.

Данные о трёх тренерах, площадках и времени занятий взяты из сообщения заказчика. Общая история клуба частично опирается на страницу федерации: https://fcjj.tomsk.ru/federation/schools/sparta/. Для фото предусмотрена папка `public/photos`; точные имена файлов перечислены в её README.

Текстовое название в интерфейсе — «СПАРТА». Шрифты Fira Sans Extra Condensed и Inter загружаются из Google Fonts; коллекция допускает коммерческое использование. В исходной картинке эмблемы остаётся латинская надпись, поэтому для окончательной версии нужен утверждённый русскоязычный файл логотипа.

Запуск: `npm install`, затем `npm run dev`. Vite покажет локальный адрес в терминале: обычно `http://localhost:5173/`, а если порт занят — следующий свободный (`5174` и т. д.). Проверка сборки: `npm run build` и `npx tsc --noEmit`.

План интеграции с Rumi: React-фронтенд оставить отдельным, а запись, тренировки, площадки, профили, абонементы и учёт посещений подключить к API Rumi. Роли руководителя и администраторов, права на изменение расписания и уведомление записанных людей при отмене тренировки должны проверяться сервером. Текущий `/admin` — открытый демо-макет; публичный вход в него нельзя считать защитой. Форму регистрации клуба и доступ клиента потребуется связать с серверной авторизацией.
